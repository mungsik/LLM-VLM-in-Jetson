# Phi-4-mini GGUF Ko-IFEval 상태

상태: 미측정.

현재 레포에 저장된 양자화 결과는 KMMLU와 한국어 PPL까지이며, Ko-IFEval 수치는 아직 없다.
로컬 `lm-eval` 태스크 파일에는 기본 `ifeval`은 있지만 한국어 `ko_ifeval` 태스크는 확인되지 않았다.

추가한 실행 경로:

```bash
bash compression/benchmarks/run_ko_ifeval_sweep.sh
```

한국어 custom task가 없는 환경에서 파이프라인만 확인하려면:

```bash
TASK=ifeval LIMIT=20 bash compression/benchmarks/run_ko_ifeval_sweep.sh
```

실행이 완료되면 `docs/results/ko_ifeval.jsonl`이 생성되고,
`docs/results/build_quant_sweep_xlsx.py`가 엑셀의 `Ko-IFEval strict/loose` 컬럼과
`Ko-IFEval` 시트에 자동으로 병합한다.

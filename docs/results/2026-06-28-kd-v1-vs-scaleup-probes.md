**Q:** 사과 3개를 1500원에 샀고 배 2개를 2000원에 샀습니다. 과일 1개의 평균 가격은 얼마인가요? 계산 과정을 보여주세요.

### kd-v1
과일 1개의 평균 가격을 구하기 위해 다음과 같은 계산을 수행해야 합니다.

1. **총 가격 계산:**
   - 사과 3개를 1500원에 샀습니다.
   - 배 2개를 2000원에 샀습니다.
   - 총 가격은 사과와 배의 가격을 더한 값입니다:
   \[
   \text{총 가격} = 1500 + 2000 = 3500
   \]

2. **총 수량 계산:**
   - 사과 3개, 배 2개를 샀습니다.
   - 총 수량은 사과와 배의 수량을 더한 값입니다:
   \[
   \text{총 수량} = 3 + 2 = 5
   \]

3. **평균 가격 계산:**
   - 평균 가격은 총 가격을 총 수량으로 나누어 구합니다:
   \[
   \text{평균 가격} = \frac{\text{총 가격}}{\text{총 수량}} = \frac{3500}{5} = 700
   \]

따라서 과일 1개의 평균 가격은 700원입니다.
